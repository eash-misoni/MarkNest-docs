Pull Request（PR）

自分の作業ブランチで行った変更をmainへ取り込む前に、確認・レビューしてもらう提案です。

一言でいうと： 自分の作業ブランチで行った変更をmainへ取り込む前に、確認・レビューしてもらう提案です。

MarkNestでは

MarkNestではIssueに沿って実装し、検査結果をPRへ記載し、Codex・CI・人の確認を受けます。

どこで見る・使う？

MarkNestのPull requests一覧にあります。PRを開くと「Conversation」「Files changed」「Checks」などを見られます。

間違えやすい点

PRはgit pullコマンドとは別です。PRを作るだけでmainに変更が取り込まれるわけではありません。
