ローカル環境：Chrome拡張を起動する

本文の用語リンクから意味・画面での場所を確認できます。

知らない言葉は、本文中の点線付きリンクをクリックすると解説ページへ移動できます。ブラウザの「戻る」で読んでいた位置へ戻れます。

この節は本体リポジトリの起動確認段階の手順です。完成機能を保証する手順ではありません。

用意するもの

  • PC版Google Chrome（開発用プロフィールを推奨）
  • Node.js 22系、npm、Git、VS Codeなどのエディタ
  • eash-misoni/MarkNest リポジトリのクローン

実行する

git clone https://github.com/eash-misoni/MarkNest.git
cd MarkNest
npm ci
npm run check
  1. Chromeでchrome://extensions/を開き、「デベロッパーモード」をON。
  2. 「パッケージ化されていない拡張機能を読み込む」を押す。
  3. リポジトリのextension/フォルダを選択する。manifest.jsonが直接入っている場所です。
  4. MarkNestアイコンからPopupを開き、起動確認用の操作を試す。
  5. Popupを右クリックして「検証」を開き、Consoleのエラーを確認する。
  6. JSを編集したら拡張カードを「更新」し、Popupを開き直す。

検査コマンドの使い分け

コマンド 主な用途
npm ci lockfileどおり依存関係を導入
npm run check:syntax JavaScriptの構文確認
npm run check:types JSDocの型チェック（checkJs）
npm test Nodeの単体テスト
npm run check 上記の一括確認

環境構築でAWSアカウントやCognitoトークンを要求される場合は、Issueの対象範囲を確認してください。最小Popupの起動確認にはAWS接続は不要です。ブックマークの実データを使う前に、テスト用Chromeプロフィールと非破壊的な確認方法を用意します。
